# 🦷 OdontoStudio | Demo de Landing Page Médica

Sitio web demostrativo de alta conversión diseñado para **Clínicas Odontológicas y Centros de Estética Dental**. Desarrollado con arquitectura moderna, ultraligera y orientada a la captación directa de pacientes vía WhatsApp.

---

## ✨ Características Principales

- **⚡ Carga Ultrarrápida & 100% Responsive:** Maquetado con Tailwind CSS sin frameworks pesados, garantizando máxima velocidad en dispositivos móviles.
- **🔄 Comparador Interactivo de Sonrisa (Antes y Después):** Slider táctil e interactivo con soporte para mouse y pantallas touch que permite comparar casos clínicos reales.
- **📱 Formulario Inteligente de Citas WhatsApp:** Codificación y apertura automática de mensajes estructurados en WhatsApp con nombre, teléfono, especialidad y horario preferido.
- **❓ Acordeón de Preguntas Frecuentes (FAQ):** Resolución de objeciones comunes sobre anestesia indolora, obras sociales, coberturas y cuotas.
- **📍 Integración con Google Maps:** Tarjeta interactiva con mapa embebido e instrucciones de ruta directa a la clínica.
- **🚑 Barra Superior de Urgencias 24/7:** Botón directo para emergencias y dolores agudos.

---

## 🛠️ Stack Tecnológico

- **HTML5 Semántico**
- **Tailwind CSS (CDN)**
- **Vanilla JavaScript (Interacciones & Sliders)**
- **Google Fonts (Plus Jakarta Sans & Inter)**
- **Material Symbols Outlined**
